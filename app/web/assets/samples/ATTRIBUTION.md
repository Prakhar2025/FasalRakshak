# Demo sample attribution

The three sample leaf photos in this directory come from the public
PlantVillage research dataset (github.com/spMohanty/PlantVillage-Dataset,
color images), used here in demo mode so that judges and evaluators can
reproduce results without any personal data.

Files:

- early-blight.jpg: Tomato___Early_blight class sample
- late-blight.jpg: Tomato___Late_blight class sample
- healthy.jpg: Tomato___healthy class sample

No farmer or personal data appears anywhere in demo mode.
